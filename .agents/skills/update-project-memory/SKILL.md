# Update Project Memory

1. Inspect the actual repository state.
2. Read all files under `docs/`.
3. Update only documents affected by the change.
4. Keep current facts in `PROJECT_MEMORY.md`.
5. Keep current architecture in `ARCHITECTURE.md`.
6. Append significant historical decisions to `DECISIONS.md`.
7. Keep feature status in `FEATURES.md`.
8. Record MCP changes in `MCP.md`.
9. Record skill provenance and modifications in `SKILLS.md`.
10. Remove stale current state information.
11. Do not erase historical decisions.
12. Use concrete dates.
13. Do not claim work is complete unless the repository confirms it.
