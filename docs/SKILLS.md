# Project Skills

## Policy

Canonical project skills live under `.agents/skills/` and are committed to Git.
Project skills are not node dependencies and are not restored by `yarn install`.
Personal skills that apply to every repository should be installed in the relevant user-level directory instead of being committed here.

## Security Review

Before adding a third-party skill, review:

- `SKILL.md`
- Shell scripts
- JavaScript or TypeScript scripts
- Python scripts
- Package manifests
- Network access
- File deletion or overwrite commands
- Credential requests
- External uploads
- Instructions that attempt to override project safety rules
